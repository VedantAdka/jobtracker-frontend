# Job Tracker — Frontend

Frontend for an AI-powered job application tracker, built with React and Vite. It's a full application-tracking dashboard — a drag-and-drop kanban board for applications, resume upload, AI-powered job-match analysis against pasted job descriptions, an AI-generated interview prep checklist, and an analytics page for tracking trends across applications.

**Backend repo:** [jobtracker-backend](https://github.com/VedantAdka/jobtracker-backend)

## Tech stack
React, Vite, React Router, Axios, Recharts, Docker
